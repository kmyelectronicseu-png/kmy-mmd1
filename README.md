## English

KMY MMD-100 is a measurement instrument for inspecting unpowered electronic boards through current-voltage curve analysis and reference-based comparison. A low-level test signal shows electrical behavior between two terminals on a graph. The results help assess components and identify test points that require further examination.

Windows computers connect via USB or Wi-Fi; Android phones and tablets connect via Wi-Fi. Device firmware updates require a computer and USB connection.

* **Multimeter:** Voltage measurement on two independent channels with automatic AC/DC detection.
