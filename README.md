## English

KMY MMD-1 is a professional fault detection and test device that allows you to identify defective components on electronic boards without applying any power to the board. When two probes are touched to the terminals of the suspected component, the device applies a low-level test signal and normalizes the dynamic relationship between voltage and current graphically on the screen.
